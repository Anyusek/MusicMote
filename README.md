## 💜 О проекте

**MusicMote** — это лёгкое и удобное десктопное приложение для управления Яндекс Музыкой прямо с рабочего стола.

Приложение позволяет управлять воспроизведением, не открывая сам плеер, с помощью современного интерфейса и горячих клавиш.

---

## ✨ Возможности


* ▶️ Воспроизведение / пауза
* ⏭ Следующий / предыдущий трек
* 🔊 Управление громкостью
* 🚀 Запуск Яндекс Музыки
* 🪟 Переключение на окно плеера
* ⌨️ Глобальные горячие клавиши
* ⚙️ Настройка и переназначение горячих клавиш
* 🌐 Выбор языка интерфейса:
  * 🇷🇺 Русский
  * 🇬🇧 English
  * 🖥 Системный
* 🎨 Выбор темы интерфейса:
  * 🌙 Тёмная
  * ☀️ Светлая
  * 🖥 Системная
* 📌 Сворачивание в системный трей
* 📂 Выбор пути к Яндекс Музыке
* 🖱 Перетаскивание ярлыка или файла Яндекс Музыки в приложение
* 💾 Сохранение настроек приложения

## 🛠 Используемые технологии

* Python 3.10+
* CustomTkinter (GUI)
* Win32 API (pywin32)
* keyboard (горячие клавиши)
* pystray (системный трей)
* tkinterdnd2 (Drag & Drop)
* Pillow (работа с изображениями)

---

## 📦 Установка

### 🔹 Вариант 1 (рекомендуется)

Скачать готовый `.exe` файл из раздела **Releases** (или **Tags**) и запустить.

---

### 🔹 Вариант 2 (через Python)

```bash
git clone https://github.com/Anyusek/Yandex-music-controller.git
cd MusicMote
pip install -r requirements.txt
python MusicMote.py
```

---

## ⚙️ Как пользоваться

1. Запустите приложение
2. Укажите путь к Яндекс Музыке:

   * через кнопку
   * или перетащите `.exe` / ярлык в окно
3. Нажмите **"Открыть Я.Музыку"**
4. Управляйте музыкой 🎧

---

## ⚠️ Примечания

* Работает только на Windows
* Требуется установленная Яндекс Музыка
* Python 3.10+
* Для работы горячих клавиш может потребоваться запуск от имени администратора
* При отсутствии некоторых библиотек часть функций может быть недоступна

## 🔥 Глобальные горячие клавиши

MusicMote поддерживает глобальные горячие клавиши — они работают даже тогда, когда окно приложения или Яндекс Музыки не находится в фокусе.

### ⚙️ Настройка горячих клавиш

В настройках управления можно **изменить сочетания клавиш под себя**.

Также доступна возможность:

* 🔄 изменить назначение любой команды;
* 💾 сохранить собственные сочетания;
* ↩️ сбросить настройки к значениям по умолчанию.

> 💡 После изменения горячих клавиш они применяются для управления MusicMote независимо от того, какое приложение сейчас находится на переднем плане.
